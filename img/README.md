Placeholder assets are in this directory. Replace with finished corgi.software / Comet artwork when ready.

|---|---|---|
| `logo.svg` | placeholder (S + Ice Blue dot) | Navbar logo |
| `favicon.png` | **missing — add before deploy** | Browser tab icon |
| `social-card.png` | **missing — add before deploy** | Open Graph / Twitter card |
| `app-icon.png` | optional | Larger logo variant |

## Generating brand assets

The `corgisoftware-brand` skill has a `generate_social_card.py` script that produces an Open Graph card with the corgi.software palette. Run that to make `social-card.png`.

For favicon, drop a 32x32 or 64x64 PNG of the Comet mascot icon in here.
